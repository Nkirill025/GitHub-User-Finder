## Описание программы
*"GitHub User Finder — это простое графическое приложение (GUI),
разработанное на языке программирования Python. Оно предназначено 
для быстрого поиска пользователей на платформе GitHub и управления 
персональным списком избранных профилей."*
## Требования для запуска
Что нужно установить на компьютер:
- Python 3.10 или выше
- Библиотеки: `pip install requests`
## Как запустить
```bash
git clone https://github.com/Nkirill025/GitHub-User-Finder
cd GitHub-User-Finder
python main.py
```
## Как пользоваться
1.Запустите программу.
2.Введите имя пользователя в поле поиска.
3.Нажмите «Поиск».
4.Выберите пользователя из списка.
5.Нажмите «Добавить в избранное» (пользователь будет помечен ★ и сохранён в файл favorites.json).
## Пример работы
Добавление записи:
1.Вводим в поле torvalds.
2.Нажимаем «Поиск».
3.В списке появляется torvalds.
4.Выбираем torvalds.
5.Нажимаем «Добавить в избранное».
6.В списке torvalds теперь отображается как ★ torvalds.
