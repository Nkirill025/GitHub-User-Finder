## Описание программы
*"GitHub User Finder — это простое графическое приложение, разработанное на языке Python с использованием библиотеки tkinter. Программа предназначена для быстрого поиска пользователей на платформе GitHub и управления персональным списком избранных профилей."*
## Требования для запуска
Что нужно установить на компьютер:
- Python 3.10 или выше
- Библиотеки: `pip install requests`
## Как запустить
```bash
git clone https://github.com/Nkirill025/GitHub-User-Finder
cd GitHub-User-Finder
python main.py
```
## Как пользоваться
1.Запустим приложение.На экране появится окно с полем для ввода, кнопками и списком.
2.Введем логин пользователя GitHub.В текстовое поле введите интересующий вас логин (например, torvalds, 3.octocat или любую часть имени).
4.Нажмем кнопку «Поиск».Программа отправит запрос к GitHub API и отобразит найденных пользователей в списке ниже.
5.Выберем пользователя из списка.Кликнем по нужному имени в списке результатов.
6.Добавим пользователя в избранное.Нажмем кнопку «Добавить в избранное». Если пользователь ещё не был в избранном, его имя в списке будет помечено символом ★. Данные сохраняются в файл favorites.json.
Повторный просмотр избранных.При следующем запуске программы или после нового поиска избранные пользователи будут отображаться с пометкой ★.
## Пример работы
Добавление записи:
1.В поле поиска вводим: torvalds.
Нажмем на кнопку «Поиск».
2.В списке появится пользователь torvalds.
3.Выберем его в списке.
4.Нажмем «Добавить в избранное».
5.В списке имя изменится на ★ torvalds — это значит, что пользователь добавлен в избранное и сохранён в файл favorites.json.
